## The line

## How it works

`main.py` is deterministic — no network, no randomness, no clock. It writes the single one-line excuse (92 characters, one line, UTF-8) to `entry.txt` (or to `/output/entry.txt` when run under the make.fun harness, or to the path given as its first argument).

```sh
python3 main.py            # writes entry.txt
python3 main.py /tmp/out.txt
```

## Files

- `main.py` — the entry program
- `entry.txt` — the entry text produced by `main.py`
- `NOTES.md` — build notes
